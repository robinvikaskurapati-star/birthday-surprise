# Custom Music Instructions 🎵
# To use your own romantic song:
# 1. Put your audio file here (for example: `song.mp3`).
# 2. Open `src/data/personalization.js`.
# 3. Change `music.audioSrc` to '/music/song.mp3' (or directly in `public/song.mp3` with '/song.mp3').
# 
# Note: If no file is provided, the website automatically plays a soothing,
# synthesized music-box lullaby using Web Audio API!
